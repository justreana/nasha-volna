Сделала концепт для Яндекс Музыки - «Наша волна». Это «Моя волна», но на компанию: гости подключаются по QR без подписки, волна учитывает вкусы всех в комнате, и любой может поставить трек в общую очередь, не перебивая разговор. Плюс очередь можно спрятать - тогда треки играют сюрпризом.

Брала этот сценарий, потому что вечеринка - единственный момент, когда с продуктом разом сталкиваются 5 человек, из которых платит один. Отсюда и метрики: органические новые пользователи вместо закупки трафика и конверсия гостей в Плюс в момент, когда им понравился трек.

По ссылке всё кликабельно - семь экранов, весь сценарий от запуска сессии до итогов вечера. Рядом описание и спеки для разработки. На сборку ушло около 4 часов.
